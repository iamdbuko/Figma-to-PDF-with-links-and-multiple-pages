Choose a CMYK printer profile (.icc or .icm, up to 16 MiB).

Where can I find ICC profiles?

For a specific printer and paper, ask your printer or paper provider for a CMYK output profile. Choose its .icc or .icm file directly from Downloads or another folder; installing it in your operating system is not required.

Mac: in Finder, choose Go → Go to Folder (Shift–Command–G), then paste one of these paths:

  • /Library/ColorSync/Profiles
  • ~/Library/ColorSync/Profiles
  • /System/Library/ColorSync/Profiles

Windows: paste this into the File Explorer address bar:

%WINDIR%\System32\spool\drivers\color

Some folders may be empty or missing. Many display and device profiles are RGB; this plugin requires a CMYK printer/output profile.

Profile folder reference

When enabled, lowers resolution only for pages above the raster size limits. PDF page dimensions stay unchanged.

Save each part before continuing. Keep every PDF together with its original filename. Links between parts require a compatible desktop PDF viewer. The export pauses for up to 15 minutes between parts.

Each PDF has a 128 MiB retained-data allowance. Lower resolution or smaller parts can help large exports. For RGB raster pages and vector fallbacks, JPEG can help photo-heavy pages. Processing also needs memory beyond the PDF size.
