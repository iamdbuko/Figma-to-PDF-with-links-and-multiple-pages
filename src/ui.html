Ask your printer or paper provider for the CMYK output profile for your printer and paper. Choose its .icc or .icm file directly from Downloads; installing it is not required.

Mac — in Finder, press Shift–Command–G and paste a path:

  • /Library/ColorSync/Profiles
  • ~/Library/ColorSync/Profiles
  • /System/Library/ColorSync/Profiles

Windows — paste into the File Explorer address bar:

%WINDIR%\System32\spool\drivers\color

Some folders may be empty. Display profiles are often RGB; choose a CMYK printer/output profile.

Profile folder reference

Lowers the resolution of supported images while keeping text and shapes vector. Never adds detail beyond Figma’s export. Unsupported images keep their original resolution with a warning. Choose Original in More to keep image resolution unchanged.

Choose a CMYK printer profile (.icc or .icm, up to 16 MiB). The profile is validated before export and never uploaded.

Allow lowers resolution only for raster pages above the size limits, including RGB vector fallbacks. PDF page dimensions stay unchanged. Don’t allow stops the export when a page exceeds these limits.

Single PDF keeps all pages in one file. Split saves one PDF at a time. Save each part before continuing, within 15 minutes. Keep every part together with its original filename. Links between parts require a compatible desktop PDF viewer.

Each PDF has a 128 MiB retained-data allowance. Lower resolution or smaller parts can help large exports. Processing also needs memory beyond the PDF size. JPEG can help RGB raster pages and vector fallbacks.
