# Published v8 → v9 functionality audit

The table below records the dev.8 audit. **Dev.9 intentionally changes the interface** to two screens, exports every listed frame (remove unwanted rows via the context menu), defaults to 72 DPI, and moves static help to tooltips. It replaces the manual theme switch with the requested light design. Export-engine behavior remains covered by the existing tests. See [the interface update](INTERFACE.md).

Audit baseline: recovered published `v8-recovered` and dev.7 commit `692e786813a1a677c6bbee6253eb4e266f199c6c`, with the current audit follow-ups identified below. This is a code/coverage comparison, not a claim that every option combination was exercised in native Figma. References such as `v8-recovered:code.js:1196` identify the baseline file and line; current entry-point names remain useful as line numbers change.

## Verification and remaining gaps

- This audit reproduced the link-preview membership regression against both actual backend sources under identical Figma mocks. The follow-up protocol/link suites pass **71 tests**, including late destinations, removal/re-addition, stale scan races, unavailable-node cleanup and a successful retry. These fixes are included in the integrated development build.
- The new isolated production-bundle control suite passes **5 browser tests**: natural A–Z/Z–A with stable ties after real dragging, both drag directions, submitted frame order, inclusion/exclusion, remove/re-add/clear, backend refreshes, export locking, Figma selection versus export inclusion, RGB/CMYK settings retention, and all Raster and Vector resolution choices. These tests make no network requests or downloads. Theme persistence remains without dedicated browser coverage.
- The loader suite passes **13 tests**, including an upstream byte-loss reproduction, exact bytes through load/copy/save, direct/indirect lengths, malformed-length rejection, concurrent imports, source subarrays, native annotations, object-stream output with the exact minified production library, and superseded ordinary streams in incremental revisions. Consumed historical object/reference streams remain conservatively validated; this is a Figma importer, not a general incremental-PDF repair tool.
- Embedded-image resampling has focused tests for output dimensions, placements, profiles, masks, limits and cancellation; the integrated lifecycle suite exercises resolution settings and links. This does not establish native output dimensions for every DPI × color × compression combination. Unsupported images remain unchanged with warnings and may still exceed vector-CMYK conversion limits.
- The final integrated development build passes **258 tests**, including 46 vector-CMYK tests, 20 embedded-image resolution tests, 13 loader tests, 5 UI control tests and 32 browser lifecycle tests. Cancellation now yields across color-only instruction sequences and many short Forms. Nine scheduler tests and three production-browser tests also verify export and cancellation when zero-delay timers are deliberately stalled.
- A native RGB run stalled around page 108 and later timed out waiting for page 110. Those pages each processed in under one second independently. Chained background timers were a plausible trigger, consistent with [Chromium timer throttling](https://developer.chrome.com/blog/timer-throttling-in-chrome-88/), but Figma visibility/OS state was not instrumented. Cooperative posted-message tasks now schedule UI work and the pinned PDF library's processing waits. The two-minute watchdog and download-cleanup timer remain unchanged. A fully suspended renderer can still pause.
- Fresh Figma Desktop **Vector CMYK, 72 DPI** successfully exported the full 156-page real report using the built-in profile: 82,721,150 bytes. Independent inspection preserved all 115 annotation rectangles/destinations and all page boxes, 5,583 path-paint operations and 4,922 text-show operations. All 90 images use CMYK; all 90 image masks and 194 Alpha-mask Forms remain, with one exact destination ICC. Image pixels fell from 483,822,969 to 7,932,764. All 5,498 compressed streams passed strict zlib checks.
- All 156 CMYK pages rendered with Poppler and were inspected in contact sheets; pages 2, 136, 153 and 156 were also inspected at 150 DPI. No missing content/layout anomaly was apparent. Existing Figma Type 3 glyph-bounds warnings remain; no new stream/color/operand renderer errors were observed. This is not a physical print proof or a full-resolution visual comparison of every page.
- The final packaged build also completed a fresh Figma Desktop **Vector RGB, Same as Figma file, 72 DPI** export: 156 pages, 88,593,029 bytes. All 115 link rectangles/destinations, page boxes and vector/text drawing counts match the reference. All 1,325 compressed streams pass strict zlib checks. The original RGB ICC bytes match on every page/image; all 90 image dimensions and masks match the CMYK 72 DPI export. All 156 pages rendered and were inspected in contact sheets, with pages 136 and 153 inspected at 150 DPI; no missing content/layout defect was apparent. Only the same Figma glyph-bounds warnings occurred.
- The CMYK native run preceded the final cancellation-scheduling and superseded-stream validation adjustments; neither changes that fresh input's output semantics, and both are covered by the final suite. The final bundle's successful full RGB comparison is recorded in the aggregate result file. No customer document content is included in committed fixtures or reports.
- Existing live/stress records verify their stated fixtures, links and limits. They do not establish complete effect/blend parity with v8, every source document, Windows behavior, all PDF viewers, or physical printing. The vector-CMYK records explicitly distinguish structural checks, rendered appearance and printer-proof limitations.
- Small UX details changed: per-type link counts, newly-added highlighting, drag-target highlighting and detailed layer-analysis progress are absent or simplified. These are separate from PDF export correctness.
